# Joel Ramirez’s portfolio

A personal portfolio for Joel Ramirez, a Mechanical Engineering Technology student at NJIT. Built with plain HTML, CSS, and JavaScript.

## View locally

Double-click `index.html` to open the Home page in a browser. No installation or server is needed.

## Progress

The Home page introduces Joel and his interests using a restrained green palette. The About Me page covers his education and interests. The Projects page presents his Over Under robot and High Stakes intake mechanism with owner-provided photos. The Skills page covers teamwork, hands-on problem solving, and workshop tools. All four pages share navigation and styling. A third project is still needed for the assignment. Contact and the planned interactive features will be built in later tasks.

GitHub Pages deployment has not been verified. See `TESTING.md` for checks and outstanding verification.
